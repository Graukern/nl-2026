# Julia — презентация 02

Примеры кода соответствуют слайдам 2–17 презентации.

## Запуск одного примера

```bash
julia src/05_recursion.jl
```

## Запуск всех примеров

```bash
julia src/main.jl
```

`main.jl` запускает каждый пример в отдельном процессе Julia, поэтому одинаковые имена типов и модулей из разных слайдов не конфликтуют.

## Потоки

Пример многопоточности лучше запускать отдельно:

```bash
julia --threads auto src/16_threads.jl
```

или:

```bash
julia -t auto src/16_threads.jl
```

Порядок вывода в многопоточном примере не гарантирован.

## Pkg

`11_pkg.jl` не устанавливает пакеты автоматически, чтобы пример был безопасным и воспроизводимым. Команды из слайда выведены в консоль:

```julia
using Pkg
Pkg.add("Example")
Pkg.instantiate()
```

Для проекта с собственным окружением можно запускать Julia так:

```bash
julia --project=.
```
