# Julia — первая презентация

Этот набор примеров синхронизирован со слайдами 5–16 презентации `Julia_presentation_final____.pptx`.
В презентации и Docker-примерах используется ветка Julia 1.11, поэтому Dockerfile оставлен на `julia:1.11`, чтобы демонстрация совпадала со слайдами.

## Структура

- `05_jit.jl` — первый и повторный вызов, измерение времени;
- `06_run_commands.txt` — команды локального запуска и Docker;
- `07_Dockerfile` — контейнер для запуска набора примеров;
- `08_hello.jl` — первая программа и базовые вычисления;
- `09_types.jl` — типы и переменные;
- `10_operations.jl` — арифметика, логика и строки;
- `11_conversion.jl` — конструкторы, `convert`, `parse`, `promote`;
- `12_collections.jl` — массивы, матрицы, кортежи, словари и диапазоны;
- `13_scope_demo.jl` и `13_hard_local.jl` — примеры со слайда об областях видимости;
- `14_functions.jl` — формы функций и аргументы;
- `15_multiple_dispatch.jl` — типы, методы и диспетчеризация по нескольким аргументам;
- `16_broadcasting.jl` — точечные операции и dot fusion;
- `main.jl` — последовательный запуск основных примеров.

## Запуск

Из каталога `01/src`:

```bash
julia 08_hello.jl
julia main.jl
```

## Docker

Из каталога `01/src`:

```bash
docker build -f 07_Dockerfile -t julia-app .
docker run --rm julia-app
```

Для интерактивного REPL:

```bash
docker run --rm -it julia:1.11
```

## Примечание по времени JIT

`@time` зависит от машины, версии Julia и состояния процесса. Числа на слайде являются примером; при вашем запуске они будут другими. Смысл примера — сравнить накладные расходы первого запуска и повторного выполнения в одном процессе.
