# Примеры к презентации по Odin

Каждый файл — самостоятельная программа (`package main`).
Проверено на Odin `dev-2026-10`.

Запуск одного файла:

```sh
odin run examples/01_hello.odin -file
```

Примеры 26 и 28 читают `numbers.txt` из текущей директории:

```sh
cd examples && odin run 28_final.odin -file && cat result.txt
```
